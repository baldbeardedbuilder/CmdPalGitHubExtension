## A small extension, not a browser replacement

You can do the quick checks in Command Palette and open GitHub when you need the full conversation, editor, or workflow logs. You'll need Windows and PowerToys with Command Palette enabled.

This extension is still early. Installation currently starts with a source build, and **Saved Queries** is a placeholder, not a working feature.
